# Полная и демо-версии «Линзы»

Документ фиксирует пользовательские различия редакций. Обе версии используют
совместимые файлы запросов и один серверный формат диалогов, поэтому знакомство
с демо-версией не создает отдельный рабочий процесс.

| Возможность | Полная версия | Демо-версия |
|---|---|---|
| Выполнение запросов | Да | Да |
| Файлы списков `.q1cs` и отдельных запросов `.q1c` | Да | Да |
| Параметры запросов | Да | Да |
| Ограничение количества выводимых строк | Да | Да |
| Автосохранение текущего файла | Да | Да |
| Редактор запроса | «Профессиональный» или «Стандартный» на выбор | Только «Стандартный» |
| Фоновое выполнение запросов | Да | Нет |
| Навигатор пакетов и временных таблиц | Да | Нет |
| Нормализация запроса | Да | Да |
| Штатный конструктор запросов 1С | Да | Да |
| Текст и исполняемый код для Конфигуратора | Да | Да |
| ИИ-агент с работой по метаданным и изменением текста запроса | Да | Да |
| Изменение значений и списочности параметров силами ИИ | Да | Нет, параметры меняются пользователем вручную |
| История и выбор диалогов | Да | Да |
| Мастер внешнего отчета `.erf` | Да | Да |
| Мастер внешней обработки `.epf` | Да | Да |
| Темы интерфейса ИИ | «Графит», «Тепло», «Сталь», «Дилемма», «Терракота» | «Графит», «Тепло», «Дилемма» |
| Компонента шифрования и защищенная отправка запросов | Да | Да |
| Канал обновлений и ключ продукта | Для полной версии | Отдельные для демо-версии |

## Принцип разделения

Демо-версия не отключает функции, которые защищают работу пользователя:
ограничение вывода снижает риск перегрузить клиент большим результатом, а
автосохранение помогает восстановить запрос после сбоя. Различие редакций
строится вокруг профессиональных средств разработки и выполнения, а не вокруг
риска потери данных.

Сохраняемые настройки форм должны быть независимы для каждой редакции. При этом
файлы запросов и серверные диалоги намеренно совместимы. Цены, доступные модели
и стартовый баланс определяются серверной политикой продукта и в эту таблицу не
зашиваются.
